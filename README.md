# Radiator Selector

Radiator Selector - расширение для pyRevit, которое подбирает радиаторы для помещений модели Revit по требуемой тепловой мощности и ширине окна.

Изначально проект появился как попытка автоматизировать ручной подбор отопительных приборов по каталогу. Плагин собирает данные из модели, проверяет их, подбирает подходящую позицию и выводит подробный отчёт по каждому помещению.

Текущая версия работает только в режиме анализа: она читает модель, но ничего в ней не изменяет.

## Возможности

Radiator Selector:

* собирает помещения и окна из модели Revit;
* обрабатывает элементы в фазе активного вида;
* определяет связь окон с помещениями через `FromRoom` и `ToRoom`;
* получает ширину окна из параметра типа;
* считывает требуемую тепловую мощность помещения;
* загружает каталог радиаторов из CSV;
* проверяет исходные данные перед подбором;
* выбирает радиатор по мощности и габаритам;
* выводит результаты, предупреждения и ошибки в окне pyRevit.

Обработка одного проблемного помещения не останавливает проверку всей модели.

## Как работает подбор

Для каждого помещения плагин ищет одно связанное наружное окно и получает:

* требуемую тепловую мощность помещения;
* ширину окна;
* доступные позиции из каталога.

Радиатор считается подходящим, если одновременно выполняются два условия.

### Ограничение по длине

Длина радиатора должна составлять от 50 до 85% ширины окна:

```text
0,50 × ширина окна ≤ длина радиатора ≤ 0,85 × ширина окна
```

### Запас тепловой мощности

Желательный запас мощности:

```text
от 10 до 15%
```

Допустимый запас:

```text
более 15%, но не более 20%
```

Если найдено несколько подходящих вариантов, выбирается радиатор с наименьшей теплоотдачей.

Если позиции с желательным запасом нет, плагин может выбрать прибор с допустимым запасом и вывести предупреждение.

Текущая версия рассчитана на следующую конфигурацию:

* pyRevit 6.5.3.26176+2017;

## Установка

1. Скачайте репозиторий или клонируйте его:

```bash
git clone https://github.com/KOT-B-CMETAHKE/Radiator-Selector.git
```

2. Скопируйте папку:

```text
Radiator selector.extension
```

в папку расширений pyRevit. Стандартный путь в Windows:

```text
%APPDATA%\pyRevit\Extensions
```

3. Перезапустите Revit или выполните перезагрузку pyRevit.

4. В ленте Revit должна появиться вкладка `Radiator selector`.

## Подготовка модели

### Помещения

Плагин обрабатывает помещения, относящиеся к фазе активного вида.

Помещение должно:

* быть размещено в модели;
* иметь площадь больше нуля;
* иметь корректную геометрию;
* содержать параметр `Требуемая тепловая мощность`;
* иметь одно связанное наружное окно.

### Требуемая тепловая мощность

В помещении должен существовать параметр:

```text
Требуемая тепловая мощность
```

Параметр должен:

* иметь тип данных «Мощность»;
* содержать значение больше нуля.

Плагин не рассчитывает теплопотери самостоятельно. Требуемая мощность должна быть рассчитана заранее и записана в модель.

### Окна

Ширина окна считывается из стандартного параметра типа `Ширина`.

Значение должно быть больше нуля.

Связь окна с помещением определяется средствами Revit. Если окно не связано с помещением или одновременно связано с двумя помещениями, это будет отражено в отчёте.

## Каталог радиаторов

Каталог находится рядом с файлами плагина и должен называться:

```text
radiators.csv
```

Используется разделитель `;`.

Обязательные столбцы:

| Столбец       | Назначение                         |
| ------------- | ---------------------------------- |
| `Артикул`     | Уникальный идентификатор радиатора |
| `Теплоотдача` | Номинальная теплоотдача, Вт        |
| `Длина`       | Длина радиатора, мм                |

Поддерживаются русские и английские названия:

| Русское название | Английское название |
| ---------------- | ------------------- |
| `Артикул`        | `Article`           |
| `Теплоотдача`    | `Heat transfer`     |
| `Длина`          | `Length`            |

Пример:

```csv
Артикул;Теплоотдача;Длина
RS1-B-T22-H0500-L0800;1410;800
RS1-B-T22-H0500-L1000;1760;1000
RS1-B-T22-H0500-L1200;2110;1200
```

Дополнительные столбцы допускаются и не участвуют в подборе.

### Формат артикула демонстрационного каталога

Пример:

```text
RS1-B-T22-H0500-L1000
```

Расшифровка:

* `RS1` - серия демонстрационного каталога;
* `B` - нижнее подключение;
* `T22` - тип радиатора;
* `H0500` - высота 500 мм;
* `L1000` - длина 1000 мм.

Артикулы внутри каталога должны быть уникальными.

## Демонстрационные данные

Встроенный файл `radiators.csv` содержит синтетические значения теплоотдачи и предназначен для проверки работы алгоритма.

**Каталог нельзя использовать для реального проектирования, закупки оборудования или подготовки рабочей документации.**

Перед практическим применением необходимо заменить его каталогом с проверенными характеристиками оборудования и убедиться, что теплоотдача указана для требуемого температурного режима.

Автор проекта не несёт ответственности за решения, принятые на основании демонстрационных данных.

## Результат работы

После запуска pyRevit выводит:

* количество найденных помещений;
* количество успешно обработанных помещений;
* количество помещений с предупреждениями;
* количество помещений с ошибками;
* окна, для которых не удалось определить помещение;
* требуемую мощность каждого помещения;
* артикул выбранного радиатора;
* теплоотдачу радиатора;
* фактический запас мощности;
* коды найденных ошибок и предупреждений.

Пример результата:

```text
Помещение 101 - «Жилая комната»
Требуемая тепловая мощность: 1540 Вт
Подобранный радиатор: RS1-B-T22-H0500-L1000
Мощность радиатора: 1760 Вт
Запас: 14.29%
Статус: OK
```

## Ограничения версии 1.0

В текущей версии:

* модель обрабатывается только в режиме чтения;
* результаты не записываются в параметры Revit;
* радиаторы не размещаются в модели;
* поддерживается только одно связанное наружное окно на помещение;
* помещения без окон пропускаются;
* связанные модели Revit не обрабатываются;
* плагин использует фазу активного вида;
* требуемая тепловая мощность должна быть рассчитана заранее;
* встроенный каталог является демонстрационным;
* интерфейс выбора внешнего каталога отсутствует.

## Структура проекта

```text
Radiator selector.extension/
└── Radiator selector.tab/
    └── Radiator selector.panel/
        └── Radiator selector.pushbutton/
            ├── script.py
            ├── handler.py
            ├── selector.py
            ├── catalog.py
            ├── displayer.py
            ├── models.py
            ├── radiators.csv
            ├── bundle.yaml
            └── icon.png
```

Основные модули:

* `script.py` - сбор данных из Revit;
* `handler.py` - управление обработкой помещений;
* `selector.py` - подбор радиатора;
* `catalog.py` - загрузка и проверка CSV;
* `displayer.py` - вывод результатов;
* `models.py` - статусы, ошибки и служебные модели.
